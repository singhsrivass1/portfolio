# Portfolio

Personal portfolio built to showcase my projects, learning journey, and interests across AI/ML, software engineering, and problem solving.
Designed with a minimal, typography-first approach inspired by modern product design systems.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

## Sections

- About
- Projects
- Skills
- Learning Journey
- AI Playground
- Contact

## Featured Projects

- Krafti — AI-assisted product listing generator
- Smart Financial Agent
- WhatsApp Chat Analyzer

## Run Locally
(cmd)
npm install
npm run dev
